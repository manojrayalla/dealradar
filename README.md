# DealRadar

Responsive static deal discovery dashboard. Includes search, category filtering, sorting by score/discount/price, and saved deals in browser localStorage.

**Important:** listed prices and deals are illustrative, not live. Add retailer/affiliate data feeds and a scheduled backend before presenting offers as current.

## Deploy
GitHub Actions deploys the site to GitHub Pages on pushes to `main`. In repository Settings → Pages, choose **GitHub Actions** as the source. Expected site URL: https://manojrayalla.github.io/dealradar/

Deployment workflow updated to enable GitHub Pages during setup.
